# AI Knowledge Assistant

An AI-powered document question-answering system built with Python, FastAPI, RAG, embeddings, vector search, and an LLM.

## Project Goals

- Upload and process documents
- Extract and chunk text
- Generate embeddings
- Store document embeddings in a vector database
- Retrieve relevant information using semantic search
- Generate contextual answers using an LLM
- Expose the application through REST APIs
- Containerize the application using Docker
- Deploy the application on AWS

## Technology Stack

- Python
- FastAPI
- LangChain
- LLM API
- Embeddings
- Vector Database
- Docker
- Git/GitHub
- AWS
